# RE:ROOM AI — Premium Mobile Frontend

A polished, mobile-first RE:ROOM AI implementation built from the supplied premium UI/UX package and integrated into the original Figma Make/Vite repository. The product retains the original interior-design concept while establishing a reusable, strongly typed frontend baseline for a React Native/Expo handoff.

## What is implemented

- **Cohesive mobile design system** — design tokens, premium cards, responsive sheets, buttons, chips, iconography, elevated surfaces, visual hierarchy, accessible focus states, and reduced-motion support.
- **Connected product experiences** — Home, Explore, AI Design Studio, AR Room Scanner, 3D Room Studio, Shopping, Product Details, Saved Designs, Projects, Construction Planning, and Profile.
- **Polished spatial UI** — visual plane detection, measurement overlays, wall snapping, anchors, collision states, scale/rotation controls, room boundaries, depth/occlusion toggles, lighting status, and a diagnostic overlay.
- **Realistic mock domain** — the supplied typed premium data package is now in `src/premium`, including **80 products**, **12 rooms**, **12 projects**, **32 recommendations**, **60 measurements**, **48 AR objects**, spatial planes, materials, palettes, notifications, activity, project budgets, and construction tasks.
- **Offline-friendly behavior** — the app has no API requirement, image fallbacks, local favorite persistence, and an explicit offline workspace control.
- **Quality foundation** — strict TypeScript, deterministic catalog/spatial utilities, data and utility tests, linting, formatting checks, and a production Vite bundle.

## React Native / Expo handoff

The target repository is a Vite React project generated by Figma Make, so this upgrade preserves the existing executable runtime instead of replacing it with an unrelated Expo project. The integrated domain contracts and screen semantics map directly to the supplied React Native baseline:

- Replace `InteriorImage` with `Image` / `expo-image` and cached local/CDN assets.
- Replace CSS components in `src/components/ui.tsx` with React Native primitives using the included `tokens`, models, and state boundaries.
- Mount a native ARKit/ARCore renderer behind the existing scanner and studio controls; the web UI deliberately communicates the required AR state without claiming to provide device hardware access.
- Swap the mock exports in `src/premium/data` for API selectors while preserving the typed models.

## Production notes

- Remote Unsplash image references are intentionally realistic placeholders. Replace them with owned, optimized CDN assets before shipping.
- The scanner and 3D studio are visual/control interfaces. Live sensor access, AR scene rendering, checkout, identity, analytics, and external project services should be connected through platform-native adapters.
- Do not expose the mock data package in an authenticated production API; it is designed as an offline prototype contract.
