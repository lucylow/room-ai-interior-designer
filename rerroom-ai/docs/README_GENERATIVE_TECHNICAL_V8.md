# RE:ROOM AI — Generative Technical V8

This extension adds a technical, deterministic demo layer for creative generative AI. It expands the previous style/palette/layout mock data into a structured generation pipeline with prompt compilation, retrieval traces, conditioning configuration, mock embeddings, model routing, preference/feedback simulation, refinement, explainability, spatial preservation, CAD/BIM awareness, and demo analytics.

## Design principle

The generative layer proposes **reversible aesthetic deltas**. Room geometry, CAD/BIM anchors, doors, windows, dimensions, and other authoritative source features remain outside the generative state.

## Demo styles

Modern, Minimalist, Scandinavian, Industrial, Japandi, Mid-century, Organic Modern, Bohemian, Contemporary, Warm Minimal, Quiet Luxury, Coastal Modern, Modern Farmhouse, Transitional, Art Deco, New Nordic, Soft Industrial, Desert Modern, Moody Modern, Eclectic Modern, Naturalist, Urban Soft, Heritage Modern, Craft Modern.

## Demo technical flow

```text
Intent
  -> Prompt Compiler
  -> Style / Palette Retrieval
  -> Layout + Spatial Constraints
  -> Mock Conditioning
  -> Model Router
  -> Deterministic Generator
  -> Quality / Geometry Gates
  -> Concept Ranking
  -> Explainability
  -> Iterative Refinement
```

The dataset is synthetic except for the generic domain concepts. No claim is made that the mock records are production model outputs.
