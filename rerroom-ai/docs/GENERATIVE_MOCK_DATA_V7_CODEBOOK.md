# Codebook — Generative Mock Data V7

This package is structured as a deterministic demo-data and AI-behavior layer. It is intentionally separate from production model providers and retail truth.

## Collections
Style profiles, palettes, layout advice, concepts, refinements, furniture aesthetic mappings, user profiles, scenarios, prompt templates, moodboards and gallery projects.

## APIs
Use `generateMockCreativeDesign()` for deterministic creative generation, `styleFilter()` / `paletteFilter()` for filter UI, `explainConcept()` for rationale, and `runGenerativeMockDataQA()` for data integrity checks.
